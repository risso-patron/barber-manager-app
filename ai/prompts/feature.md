# Objetivo

Este procedimiento define el proceso oficial para diseñar, validar e implementar una nueva funcionalidad en Ornó.

No comenzar a escribir código hasta completar el análisis.

---

# Paso 1 - Comprensión

Responder:

- ¿Qué problema resuelve?
- ¿Quién lo necesita?
- ¿Qué valor aporta?
- ¿Es parte del MVP?
- ¿Existe algo similar actualmente?
