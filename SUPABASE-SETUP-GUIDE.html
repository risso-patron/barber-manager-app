👤 Paso 6: Crear Primer Usuario Admin

⚠️ Este paso lo harás DESPUÉS de registrarte en la app

Proceso:

  1. Primero, regístrate en tu aplicación usando el formulario de registro
  2. Luego, ve a Supabase → Table Editor → users
  3. Busca tu usuario por email
  4. Haz clic en el campo role
  5. Cámbialo de client a admin
  6. Guarda los cambios

Alternativa (usando SQL):

-- Reemplaza 'tu-email@ejemplo.com' con tu email real
UPDATE public.users 
SET role = 'admin' 
WHERE email = 'tu-email@ejemplo.com';
