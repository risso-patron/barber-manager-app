Desplazamiento y encabezado fijo
El encabezado es fijo con fondo translúcido y desenfoque; el contenido pasa por debajo. El borde inferior solo aparece al desplazar. La barra lateral se desplaza de forma independiente; el selector de local y el usuario quedan siempre visibles. Las barras de herramientas de tablas pueden fijarse bajo el encabezado (top: 64px). Los modales y la paleta bloquean el desplazamiento del fondo.
Arquitectura de tema
Todos los colores se consumen como variables semánticas (--superficie, --tinta-2, --primario), nunca valores directos. Claro es el producto. El tema oscuro futuro será un remapeo de las mismas variables — cálido, nunca el negro azulado anterior — sin tocar componentes. El conmutador ya existe en el menú de usuario, deshabilitado, como promesa visible.
