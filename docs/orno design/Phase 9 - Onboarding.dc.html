Reglas del asistente
Una pregunta por pantalla. Todo tiene default inteligente. Todo es salteable menos el nombre — y saltear dice qué pasa («usaremos el horario típico»). Se puede cerrar y retomar: el progreso persiste. Nunca pide tarjeta.
Estados
Guardado optimista por paso (nunca «Guardar»). Error de red: el paso queda en local y se reintenta solo — banda discreta. Volver a entrar retoma donde quedó. El enlace final funciona aunque falten pasos opcionales.
Accesibilidad
Barra de progreso con aria-valuenow; cada paso anuncia su título (aria-live). Objetivos ≥48px. Enter avanza cuando el paso está completo. Los toggles de días son switches reales con etiqueta del día + horario, nunca solo color.
