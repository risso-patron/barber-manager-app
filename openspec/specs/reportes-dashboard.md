# Especificación: Reportes y Dashboard

## Escenario: Visualización de métricas clave
- Admin accede al dashboard.
- El sistema muestra métricas: citas totales, ingresos, servicios más vendidos.

## Escenario: Filtros por fecha, servicio, empleado
- Admin aplica filtros en el dashboard.
- El sistema actualiza las métricas y reportes según los filtros.
